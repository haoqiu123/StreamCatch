StreamCatch

Find web videos. Save them locally.

01Keep the folder

Move the entire StreamCatch folder somewhere you will keep, such as Documents.

02Load the extension

Open chrome://extensions in Chrome. Enable Developer mode, click Load unpacked, and select the extension folder beside this file.

03Install the Mac helper

Install Homebrew first, then open 安装Mac助手.command. Enter y if prompted to install dependencies. Wait for 安装完成 (installation complete).

If double-clicking does not launch the script, review it first. Type zsh in Terminal, drag the script into the window, and press Return.

04Start downloading

Play a video on its original page and open StreamCatch. 本地助手已连接 means the helper is ready. Choose a quality and click 下载 (Download).

Save location: Downloads → StreamCatch. Downloads continue when the popup closes; keep the browser running.
