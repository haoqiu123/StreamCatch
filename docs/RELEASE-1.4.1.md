## 下载与安装

Mac 用户下载下面 Assets 中的 **StreamCatch-macOS.zip**。解压后按 `开始安装.html` 操作：Chrome 开启开发者模式、加载 `extension` 文件夹，再运行 `安装Mac助手.command`。首次安装助手需要 Homebrew。

仅需要扩展时下载 **StreamCatch-extension.zip**。SHA256SUMS.txt 可用于核对文件。

Mac 助手输出兼容 MP4；Windows / Linux 暂无对应助手安装器，DRM 内容不支持。
